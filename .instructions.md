# Agent Usage Instructions

- How to invoke: Provide the raw ticket text and any attachments (logs, screenshots, environment). Include reproduction steps if available.
- Expected output (recommended JSON schema):
  {
    "summary": "",
    "category": "",
    "priority": "",
    "missing_info": [],
    "actions": [],
    "assignee": ""
  }

- Example
  Input: "App crashes on start with NullReferenceException when opening settings."
  Output (JSON):
  {
    "summary": "App crashes when opening settings (NullReferenceException)",
    "category": "Bug",
    "priority": "High",
    "missing_info": ["OS version", "Steps to reproduce"],
    "actions": ["Collect full stack trace", "Reproduce locally with provided steps"],
    "assignee": "backend-team"
  }

- Maintenance
  - To change behavior, update `.agent.md` system prompt or guidelines.
  - Keep privacy in mind: remove or redact PII from tickets before sharing.

- Troubleshooting
  - If agent output is vague, provide more context or logs and re-run.
